# 手机访问指南（纯网页版，不需要安装 App）

三种方式，按需要选：

| 方式 | 适合场景 | 网址形式 | 需要网络吗 |
|---|---|---|---|
| 方式一 局域网 | 在家 / 办公室，电脑开着 | http://192.168.x.x:8000 | 同一个 Wi-Fi |
| 方式二 GitHub Pages | 随时随地都能打开，推荐 | https://byc2003.github.io/仓库名/ | 需要 |
| 方式三 传文件 | 临时看一次 | 本地文件 | 不需要 |

不管用哪种方式，**进度同步**都用同一套方法（见文末），手机和电脑的进度会自动合并。

---

## 方式一：局域网访问（今天就能用）

1. 双击 `E:\Project\0基础学agent\启动本地服务.bat`。
2. 窗口里会列出手机访问地址，形如 `http://192.168.1.5:8000`。
3. Windows 弹出防火墙提示时，勾选「专用网络」并点「允许访问」。
4. 手机连上**同一个 Wi-Fi**，在浏览器输入那个地址即可。
5. 电脑上这个窗口不能关；关了服务就停了。

小提示：

- 手机浏览器建议用 Chrome、Edge 或 Safari。
- 如果打不开：确认手机和电脑是同一个 Wi-Fi（不是手机流量）、确认防火墙已允许、把电脑上窗口里的地址重新念一遍（IP 可能变）。
- 公司/学校网络常做隔离，同一 Wi-Fi 也可能互相访问不了，改用方式二。
- 局域网地址是 http 开头，浏览器可能提示「不安全」——这是正常的，它只在你家网络内。

## 方式二：发布到 GitHub Pages（推荐，随时随地打开）

发布后你会得到一个公网网址，手机在任何地方都能打开。

### 第一步：把平台代码推到 GitHub

在 VS Code 里打开 `E:\Project\0基础学agent`，打开终端（Ctrl + `），执行：

```powershell
git init
git add .
git commit -m "feat: Agent 学习平台（学习路线 + 实战教程 + 云同步）"
git branch -M main
git remote add origin https://github.com/BYC2003/agent-learning-platform.git
git push -u origin main
```

注意：要去 github.com 先新建一个仓库，名字建议 `agent-learning-platform`，**创建时不要勾选 Add README**（否则推送会冲突）。

### 第二步：打开 Pages 功能

1. 浏览器打开这个仓库 → 上方 **Settings**。
2. 左侧菜单找到 **Pages**。
3. Source 选 **Deploy from a branch**，Branch 选 **main**，目录选 **/ (root)**，点 Save。
4. 等 1-2 分钟，页面顶部会显示你的网址，形如：
   `https://byc2003.github.io/agent-learning-platform/`

### 第三步：手机打开并收藏

- 手机浏览器输入这个 https 网址。
- 用浏览器菜单里的「添加到主屏幕」，桌面上就会出现一个图标，点开就是全屏网页（这只是快捷方式，不是 App）。
- 收藏后下次直接点图标进入。

## 方式三：把文件传到手机（临时方案）

1. 把整个 `0基础学agent` 文件夹压缩成 zip，用微信/QQ 发给自己。
2. 手机解压后，用支持打开本地 HTML 的浏览器或文件管理器打开 `index.html`。
3. 缺点：本地打开时部分浏览器功能受限，进度也不容易同步，只适合临时看内容。

## 进度同步：手机和电脑互通

用的是你已有的 GitHub 账号，不需要服务器、不需要装 App。

### 第一次配置（电脑和手机各做一次）

1. 在平台上打开左侧菜单里的 **云同步进度**。
2. 点「打开 GitHub 创建令牌」按钮（页面已经帮你勾好 `gist` 权限）。
3. 拉到底部点 **Generate token**，复制 `ghp_` 开头的那串字符（只显示这一次）。
4. 回到平台，把令牌粘贴到输入框，点「**保存并连接**」。
5. 手机上打开同一个网址 → 进入「云同步进度」→ 粘贴令牌 → 保存并连接。

连接成功后，手机会自动找到电脑创建的那份云端备份并合并进度。

### 合并规则（不会覆盖丢数据）

| 内容 | 规则 |
|---|---|
| 任务 / 练习 / 面试题勾选 | 取并集，两边勾过的都保留 |
| 练习笔记、步骤笔记 | 同一处都有内容时，保留更完整的那份 |
| 学习日志 | 按「日期 + 内容」去重后合并 |
| 番茄钟数量 | 取两边较大的值 |

同步完成时会把合并结果写回云端，所以两边最终完全一致。

### 自动同步

- 开启自动同步后：手机上每完成一次操作，6 秒后自动上传；打开页面时自动拉取合并。
- 想省流量可以关掉，改成手动点「立即同步（合并两端）」。

### 安全提示

- 令牌只存在你本机浏览器的本地存储里，只发给 GitHub。
- 云端备份是**私有 Gist**，只有你的账号能看。
- 不要在别人的电脑上粘贴令牌；怀疑泄露就去 GitHub 设置里撤销并重新生成。
- 清理浏览器数据会清掉令牌和本地进度，重要节点用顶栏 ↓ 再导出一份。

### 不想用云同步的备用方案

电脑点顶栏 **↓** 导出 JSON → 用微信发给自己 → 手机打开页面点 **↑** 导入。反过来也一样。

## 常见问题排查

| 现象 | 原因与解决 |
|---|---|
| 手机打不开局域网地址 | 确认同一 Wi-Fi、防火墙已允许、地址里的端口是 8000 |
| 打开显示目录列表而不是平台 | 说明访问的不是 index.html 所在目录，检查服务是否在平台根目录启动 |
| 云同步报「令牌没有 gist 权限」 | 重新生成令牌，勾选 gist |
| 云同步报「无法连接」 | 电脑/手机需要能访问 github.com；国内网络可能需要开启代理 |
| GitHub Pages 打开是 404 | 检查 Pages 设置里分支选的是 main、目录是 / (root)，并等 1-2 分钟 |
| 手机上菜单找不到 | 窄屏时点左上角的 ≡ 按钮展开菜单 |
