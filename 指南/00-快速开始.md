# 快速开始：今天就能动手

## 一、打开学习平台

双击 `E:\Project\0基础学agent\index.html`，用 Chrome 或 Edge 打开即可。

- 不用装环境，不用起服务，不用联网（GitHub 链接需要联网才能点开）。
- 建议按 `Ctrl + D` 把页面加入收藏夹。
- 学习进度保存在浏览器本地，换电脑前点顶栏 **↓** 导出备份。

## 二、平台里有什么

| 模块 | 用途 |
|---|---|
| 学习总览 | 你的定制路线、入口自测、阶段进度、每日节奏 |
| 学习路线 | 阶段 0-9，共 103 个任务、27 个练习，逐个打卡 |
| 项目实战教程 | **8 个实战项目、82 个详细步骤**，含软件操作、命令、预期结果与报错处理 |
| 作品集看板 | 3 个旗舰作品的交付清单与简历写法 |
| 面试题库 | 20 道高频题 + 答题要点 |
| 学习日志 | 每天记录，可导出 Markdown |
| 番茄钟 | 25 分钟专注计时 |

## 三、开始前的 10 分钟

1. 打开平台 → 进入 **学习总览** → 在最上方找到「入口自测」。
2. 勾选你已经确定会做的 8 项（Git、VS Code、Python 基础、pip、写测试、调 API、async）。
3. 页面会直接告诉你该从哪个阶段开始：
   - 勾选 ≤ 3 项 → 从阶段 1 补基础
   - 勾选 4-6 项 → 从阶段 2 开始
   - 勾选 ≥ 7 项 → 直接进阶段 3
4. 进入 **项目实战教程**，按 实战 01 → 实战 08 的顺序往下做。

## 四、你的第一个项目（建议今天完成）

**实战 01：环境标准化 + Git 工作流**

1. 在 `E:\Project\0基础学agent\实战项目` 下新建文件夹 `t1-hello-agent`。
2. 用 VS Code 打开这个文件夹（文件 → 打开文件夹）。
3. 按平台里「实战 01」的 10 个步骤一步步做，每一步都写明了：
   - 在哪个软件操作（VS Code / 终端 / 浏览器 / 文件资源管理器）
   - 具体执行什么命令
   - 应该看到什么结果
   - 报错怎么解决
4. 做完后，代码会被推送到你的 GitHub 仓库 `BYC2003/git123`。

## 七、每天怎么用

1. 打开平台 → 看「接下来做什么」。
2. 打开番茄钟，专注 25 分钟。
3. 做实战教程的一个步骤，勾选它，遇到问题把报错记在步骤笔记里。
4. 收工前写一条学习日志（学了什么、卡在哪）。
5. 每周日点「导出」备份进度，并回顾本周完成度。
