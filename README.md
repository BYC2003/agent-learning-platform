# Agent 应用开发学习平台

一个**纯本地、双击即用**的 Agent 学习工作台，把 24 周学习路线 + 8 个实战项目教程做成了可以打卡、练习、记录和复盘的网页。

## 一、怎么打开

双击 `E:\Project\0基础学agent\index.html`（推荐 Chrome / Edge）。

- 不需要安装任何东西，不需要启动服务器，不需要联网。
- GitHub 链接需要联网才能跳转，其余功能全部离线可用。
- 进度保存在浏览器本地，换电脑前点顶栏 **↓** 导出备份，新环境点 **↑** 导入恢复。

## 二、功能一览

| 模块 | 说明 |
|---|---|
| 学习总览 | 你的定制路线、入口自测（自动推荐起点）、阶段进度、每日节奏、18 周计划 |
| 学习路线 | 阶段 0-9，共 103 个任务、27 个动手练习，逐个打卡 |
| 项目实战教程 | **8 个项目、82 个详细步骤**，每步都写明在哪个软件操作、执行什么命令、预期结果、常见报错、改造方向 |
| 作品集看板 | 3 个旗舰作品的 33 项交付清单，附可直接复制的简历写法 |
| 面试题库 | 20 道高频题 + 答题要点，支持分类筛选与「只看未掌握」 |
| 学习日志 | 每天记录学习内容与时长，可导出 Markdown |
| 全局搜索 | 搜任务、知识点、练习、作品、面试题，点击直达 |
| 番茄钟 | 25 分钟专注计时，统计完成数量 |

## 三、8 个实战项目

| 编号 | 项目 | 复刻来源 | 难度 |
|---|---|---|---|
| 实战 01 | 环境标准化 + Git 工作流 | 自建 | 打基础 |
| 实战 02 | FastAPI + 流式输出的 LLM 服务 | 自建 | 必做 |
| 实战 03 | 工具 Agent | openai/openai-agents-python | 必做 |
| 实战 04 | 企业级 RAG 知识库 | run-llama/llama_index、infiniflow/ragflow | 核心 |
| 实战 05 | MCP 工具服务器 | modelcontextprotocol/python-sdk | 前沿 |
| 实战 06 | LangGraph 工作流 + 人工审批 | langchain-ai/langgraph | 核心 |
| 实战 07 | 浏览器操作 Agent | browser-use/browser-use | 前沿 |
| 实战 08 | 上线工程化（Docker / 可观测 / CI） | langfuse/langfuse、promptfoo/promptfoo | 必做 |

每个教程的步骤结构：

```
第 N 步：标题
  在 [哪个软件] 操作        ← VS Code / 终端 / 浏览器 / 文件资源管理器
  做什么                   ← 具体动作清单
  在终端执行               ← 可一键复制的命令
  代码（如果需要）          ← 可一键复制的代码块
  预期结果                 ← 做对了应该看到什么
  提示 / 踩坑              ← 常见错误与解决办法
  这一步的笔记             ← 自动保存，记录你实际遇到的问题
```

底部还有：完成验收清单、常见报错与解决、做完之后继续改造的方向。

## 五、想改内容怎么办

所有学习内容都是数据，改文件即可，不用动逻辑：

- 想改路线 / 任务 / 练习 → 改 `data.js`
- 想改定制信息 / 自测题 / 18 周计划 → 改 `personal.js`
- 想增删实战教程 → 改 `tutorials.js`

改完保存，刷新网页即可生效。改之前建议先复制一份备份。

## 六、常见问题

**进度会丢吗？**
不会。存在浏览器本地，除非你清理浏览器数据或换浏览器。重要节点请用顶栏 **↓** 导出备份。

**能换电脑吗？**
可以。旧电脑导出 JSON，新电脑打开页面后点 **↑** 导入即可。

**手机上能用吗？**
可以，窄屏会自动切换成手机布局，点左上角 `≡` 展开菜单。

**双击打开是记事本怎么办？**
右键 → 打开方式 → 选择 Chrome 或 Edge，并勾选「始终使用此应用打开 .html 文件」。

## 七、建议的使用节奏

1. 打开「学习总览」，完成入口自测，确认起点。
2. 进入「项目实战教程」，从实战 01 开始，按步骤做。
3. 每做完一步就点「标记完成」，遇到问题写进步骤笔记。
4. 每天收工前写一条学习日志。
5. 每周日导出一次进度备份，回顾本周完成度。

## 手机上使用（纯网页版，不需要安装 App）

### 方式一：同一个 Wi-Fi 下用手机打开

1. 双击 `启动本地服务.bat`。
2. 窗口里会列出形如 `http://192.168.1.5:8000` 的地址。
3. 手机连同一个 Wi-Fi，浏览器输入该地址即可。
4. 窗口不能关，关掉服务就停了。

### 方式二：发布到 GitHub Pages（随时随地打开）

把平台代码推到 GitHub 仓库，在仓库 Settings → Pages 里把 Source 设为 `main` 分支、`/ (root)` 目录，几分钟后会得到形如
`https://byc2003.github.io/agent-learning-platform/` 的公网网址，手机在任何地方都能打开，还可以「添加到主屏幕」。

详细步骤见 `指南\手机访问指南.md`。

## 手机和电脑进度互通（云同步）

平台新增了「云同步进度」页面，用你已有的 GitHub 账号做云端备份，**不需要服务器、不需要装 App**：

1. 打开左侧菜单「云同步进度」。
2. 点按钮生成一个 GitHub 令牌（页面已帮你勾好 `gist` 权限），复制 `ghp_` 开头的字符。
3. 粘贴到输入框，点「保存并连接」。
4. 手机上打开同一个网址，重复一次（同一个账号即可）。

之后手机和电脑的进度会自动合并：

| 内容 | 合并规则 |
|---|---|
| 任务 / 练习 / 面试题勾选 | 取并集，两边都保留 |
| 笔记 | 同一处都有内容时保留更完整的一份 |
| 学习日志 | 按日期与内容去重后合并 |
| 番茄钟 | 取较大值 |

- 默认开启自动同步：完成一次操作 6 秒后自动上传；打开页面自动拉取合并。
- 也可以关掉自动，改成手动点「立即同步（合并两端）」。
- 令牌只保存在本机浏览器，云端备份是私有 Gist，可随时在 GitHub 撤销。

不想用云同步时：电脑点顶栏 **↓** 导出 JSON，用微信发给自己，手机打开页面点 **↑** 导入。
