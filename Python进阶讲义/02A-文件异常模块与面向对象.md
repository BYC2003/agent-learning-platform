# 一、文件读写

> VS Code 练法：新建 `exercises/01_io.py`。输入本课示例，`Ctrl+S` 保存，按 `Ctrl+F5`，在底部 `TERMINAL` 看结果。生成 JSON 后，在资源管理器中双击该文件查看内容。

## 1. 为什么要有文件

变量在程序退出后消失；文件用于持久化。最常见的组合是：

- 文本：`.txt`、`.md`
- 配置：`.env`、`.toml`
- 数据交换：`.json`
- 二进制：图片、压缩包

## 2. 用 pathlib 表示路径

```python
from pathlib import Path

p = Path("data") / "notes.txt"
print(p)  # data\notes.txt
```

常用接口：

```python
p.exists()
p.is_file()
p.is_dir()
p.parent
p.name       # notes.txt
p.stem       # notes
p.suffix     # .txt
p.resolve()  # 绝对路径
p.mkdir(parents=True, exist_ok=True)
```

不要手拼 `"data/" + name`。脚本读取相邻文件时用：

```python
BASE_DIR = Path(__file__).resolve().parent
DATA_FILE = BASE_DIR / "data" / "notes.txt"
```

这样无论从哪个终端目录启动，路径都稳定。

## 3. 读写文本

常见错误：只写下面这一行不会生成任何文件：

```python
path = Path("data") / "hello.txt"
```

它只是创建一个路径对象。必须调用 `mkdir()` 创建父目录，再调用 `write_text()` 写入内容。

写：

```python
from pathlib import Path

path = Path("data") / "hello.txt"
path.parent.mkdir(parents=True, exist_ok=True)
path.write_text("你好，Python\n", encoding="utf-8")
```

读：

```python
text = path.read_text(encoding="utf-8")
print(text)
```

逐行读：

```python
with path.open("r", encoding="utf-8") as f:
    for line in f:
        print(line.rstrip("\n"))
```

`with` 会在代码块结束或抛异常时自动关闭文件。

模式：

| 模式 | 含义 |
|---|---|
| `r` | 只读，不存在报错 |
| `w` | 只写，先清空，不存在则创建 |
| `a` | 追加 |
| `x` | 不存在才创建，已存在报错 |
| `rb` / `wb` | 二进制 |

危险：`w` 会立即清空原文件。重要数据先写 `.tmp`，成功后再替换。

## 4. JSON 读写

```python
import json

data = {"name": "午餐", "amount_cents": 3000, "tags": ["餐饮"]}
text = json.dumps(data, ensure_ascii=False, indent=2)
print(text)

decoded = json.loads(text)
print(decoded["amount_cents"])
```

- `ensure_ascii=False`：中文直接可读。
- `indent=2`：格式化。
- `json.dumps`：Python 对象 -> JSON 字符串。
- `json.loads`：JSON 字符串 -> Python 对象。

直接操作文件：

```python
def save_json(path: Path, data: object) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    text = json.dumps(data, ensure_ascii=False, indent=2)
    path.write_text(text, encoding="utf-8")

def load_json(path: Path) -> object:
    text = path.read_text(encoding="utf-8")
    return json.loads(text)
```

`set`、`datetime`、自定义类不能直接序列化；要转成列表、ISO 字符串或字典。

安全写入：

```python
def atomic_save_json(path: Path, data: object) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    temp = path.with_suffix(path.suffix + ".tmp")
    temp.write_text(
        json.dumps(data, ensure_ascii=False, indent=2),
        encoding="utf-8",
    )
    temp.replace(path)
```

# 二、try / except 异常处理

> VS Code 练法：新建 `exercises/02_exception.py`。先正常运行，再故意把 JSON 改成坏格式。异常发生后查看 `TERMINAL` 的 traceback；在可疑行按 `F9` 设置断点，再按 `F5` 调试。

## 1. 异常是什么

异常表示“操作无法按计划继续”。例如：

- `FileNotFoundError`：文件不存在
- `PermissionError`：权限不足
- `JSONDecodeError`：JSON 格式错误
- `ValueError`：值不合适
- `KeyError`：字典键不存在
- `IndexError`：下标越界
- `TypeError`：类型用错
- `TimeoutError`：超时
- `OSError`：系统 I/O 错误的常见父类

不处理时程序会打印 traceback 并退出。处理的目标是恢复、补充上下文、友好提示，而不是隐藏问题。

## 2. 基本结构

```python
try:
    number = int("abc")
except ValueError as exc:
    print(f"输入不是整数：{exc}")
```

完整结构：

```python
try:
    result = 10 / 2
except ZeroDivisionError:
    print("除数不能为 0")
else:
    print("只有 try 没抛错才执行", result)
finally:
    print("无论成功失败都执行")
```

顺序：`try` 成功 -> `else`；匹配异常 -> `except`；最后一定执行 `finally`。

## 3. 只捕获你能处理的异常

不推荐：

```python
try:
    data = json.loads(text)
except:
    pass
```

这会把代码 bug、键盘中断等一起吞掉。推荐：

```python
try:
    data = json.loads(text)
except json.JSONDecodeError as exc:
    print(f"JSON 错误：第 {exc.lineno} 行第 {exc.colno} 列：{exc.msg}")
```

底层无法处理时，补充上下文再抛出：

```python
try:
    text = path.read_text(encoding="utf-8")
except OSError as exc:
    raise RuntimeError(f"读取配置失败：{path}") from exc
```

`from exc` 保留原始异常链，方便排查根因。

## 4. 自定义异常

```python
class LedgerError(Exception):
    """所有记账业务异常的基类。"""

class InvalidAmountError(LedgerError):
    """金额不合法。"""

def parse_amount(text: str) -> int:
    try:
        cents = int(text)
    except ValueError as exc:
        raise InvalidAmountError("金额必须是整数分") from exc
    if cents <= 0:
        raise InvalidAmountError("金额必须大于 0")
    return cents
```

异常类一般以 `Error` 结尾。底层函数抛具体异常，业务层转换成业务异常，CLI/API 边界统一捕获并变成用户提示或 HTTP 响应。

## 5. 退出码

```python
def main() -> int:
    try:
        run()
    except LedgerError as exc:
        print(f"操作失败：{exc}")
        return 1
    return 0

if __name__ == "__main__":
    raise SystemExit(main())
```

退出码 0 表示成功，非 0 表示失败；终端、GitHub Actions 等会据此判断。

# 三、模块与包

> VS Code 练法：在资源管理器中新建 `exercises/ledger/` 文件夹和各 `.py` 文件。不要只打开单个文件；打开整个 `python-foundation` 文件夹，终端运行 `python -m ledger.cli`，VS Code 才能正确解析包。

## 1. 基本概念

- 模块：一个 `.py` 文件，例如 `storage.py`。
- 包：装模块的目录，传统写法有 `__init__.py`。
- 脚本：直接运行的文件。
- 库：可复用模块/包集合。

```text
ledger/
├─ __init__.py
├─ models.py
├─ storage.py
├─ service.py
└─ cli.py
```

## 2. 导入方式

```python
import json
from pathlib import Path
from ledger.models import Transaction
from .storage import save_transactions
```

包内相对导入中，一个点表示当前包，两个点表示上一级。不要用 `from module import *`，它让来源不清楚且易覆盖同名变量。

## 3. 入口保护

```python
def main() -> None:
    print("开始")

if __name__ == "__main__":
    main()
```

- 直接运行文件：`__name__ == "__main__"`，执行 `main()`。
- 被导入：`__name__ == "ledger.cli"`，不自动执行。
- 推荐 `python -m ledger.cli`，比 `python ledger/cli.py` 相对导入更稳定。

## 4. 循环导入

`a` 导入 `b`，`b` 又导入 `a` 会失败。解决方式：把共享模型拆到第三方模块；重新分层；万不得已才在函数内部延迟导入。

## 5. 依赖与环境

```powershell

& ".\.venv\Scripts\python.exe" -m pip install pydantic httpx pytest
& ".\.venv\Scripts\python.exe" -m pip freeze > requirements.txt
```

`.venv/` 不进 Git，`requirements.txt` / `pyproject.toml` 进 Git。

# 四、类、继承、dataclass

> VS Code 练法：新建 `exercises/04_dataclass.py`。在 `describe()` 或 `__post_init__()` 内按 `F9` 设置断点，按 `F5`，通过左侧“变量”面板观察 `self`、实例属性和传入参数。

## 1. 类与对象

类是模板，对象是实例：

```python
class Transaction:
    def __init__(self, amount_cents: int, note: str, kind: str = "expense") -> None:
        self.amount_cents = amount_cents
        self.note = note
        self.kind = kind

    def signed_amount(self) -> int:
        if self.kind == "income":
            return self.amount_cents
        return -self.amount_cents

    def describe(self) -> str:
        yuan = abs(self.signed_amount()) / 100
        sign = "+" if self.signed_amount() > 0 else "-"
        return f"{sign}{yuan:.2f} 元  {self.note}"

t = Transaction(3000, "午餐")
print(t.describe())
```

- `self` 是当前对象。
- `__init__` 初始化实例属性。
- `self.amount_cents` 每个实例独立。
- 类属性由所有实例共享。

不要在类级别用可变默认状态：

```python
class Bad:
    items = []  # 多个实例可能共享
```

## 2. 继承

继承表示“是一种”：

```python
class Animal:
    def __init__(self, name: str) -> None:
        self.name = name

    def speak(self) -> str:
        raise NotImplementedError

class Dog(Animal):
    def speak(self) -> str:
        return f"{self.name}: 汪"

class GuideDog(Dog):
    def __init__(self, name: str, owner: str) -> None:
        super().__init__(name)
        self.owner = owner
```

`super()` 调用父类实现。不要为了复用几行代码就搭七八层继承。

## 3. 组合优先

“拥有一个对象”通常比“继承一个对象”更清晰：

```python
class ApiClient:
    def fetch(self) -> dict:
        return {"ok": True}

class ReportService:
    def __init__(self, client: ApiClient) -> None:
        self.client = client

    def build(self) -> str:
        return str(self.client.fetch())
```

## 4. dataclass

自动生成 `__init__`、`__repr__`、`__eq__`：

```python
from dataclasses import dataclass, field

@dataclass
class Transaction:
    amount_cents: int
    note: str
    kind: str = "expense"
    tags: list[str] = field(default_factory=list)

t1 = Transaction(3000, "午餐")
t2 = Transaction(3000, "午餐")
print(t1)
print(t1 == t2)  # True
```

可变默认值必须用 `field(default_factory=list)`，不能直接写 `= []`。

可选参数：

```python
@dataclass(frozen=True)  # 创建后不能重新赋值
@dataclass(slots=True)   # 限制属性集合，节省内存，3.10+
```

初始化后校验：

```python
@dataclass
class Timer:
    seconds: int

    def __post_init__(self) -> None:
        if self.seconds < 0:
            raise ValueError("seconds 不能为负数")
```

重要：dataclass 的类型注解默认不做运行时校验。外部数据需要 pydantic，见 02B。
