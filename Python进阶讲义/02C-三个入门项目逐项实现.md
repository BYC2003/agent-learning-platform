## 3. 数据格式

金额用“分”存整数，避免浮点误差：

```json
{
  "version": 1,
  "transactions": [
    {
      "id": "a1b2c3",
      "amount_cents": 3000,
      "note": "午餐",
      "kind": "expense",
      "created_at": "2026-09-25T12:00:00+00:00"
    }
  ]
}
```

“30 元”存为 `3000` 分。输出时转回 `30.00 元`。不要在钱上使用 `0.1 + 0.2`。

## 4. 第一步：金额解析

内容：

```python
from decimal import Decimal, InvalidOperation

def parse_amount_to_cents(text: str) -> int:
    try:
        amount = Decimal(text)
    except InvalidOperation as exc:
        raise ValueError("金额必须是数字") from exc

    if amount <= 0:
        raise ValueError("金额必须大于 0")

    cents = amount * 100
    if cents != cents.to_integral_value():
        raise ValueError("金额最多保留两位小数")

    return int(cents)
```

先只测这个函数：

```python
import pytest
from ledger.service import parse_amount_to_cents

@pytest.mark.parametrize(
    ("raw", "expected"),

)
def test_parse_amount(raw: str, expected: int) -> None:
    assert parse_amount_to_cents(raw) == expected

@pytest.mark.parametrize("raw", ["abc", "0", "-1", "1.001"])
def test_parse_amount_invalid(raw: str) -> None:

        parse_amount_to_cents(raw)
```

## 5. 第二步：定义交易模型

可以先用 dataclass：

```python
from dataclasses import dataclass
from datetime import datetime
from typing import Literal
from uuid import uuid4

@dataclass(frozen=True)
class Transaction:
    id: str
    amount_cents: int
    note: str
    kind: Literal["income", "expense"]
    created_at: datetime

    @classmethod
    def create(cls, amount_cents: int, note: str, kind: str) -> "Transaction":
        if amount_cents <= 0:
            raise ValueError("金额必须大于 0")
        if kind not in {"income", "expense"}:
            raise ValueError("kind 必须是 income 或 expense")
        return cls(
            id=uuid4().hex[:12],
            amount_cents=amount_cents,
            note=note.strip(),
            kind=kind,
            created_at=datetime.now().astimezone(),
        )

    def to_dict(self) -> dict:
        return {
            "id": self.id,
            "amount_cents": self.amount_cents,
            "note": self.note,
            "kind": self.kind,
            "created_at": self.created_at.isoformat(),
        }

    @classmethod
    def from_dict(cls, raw: dict) -> "Transaction":
        return cls(
            id=str(raw["id"]),
            amount_cents=int(raw["amount_cents"]),
            note=str(raw["note"]),
            kind=raw["kind"],
            created_at=datetime.fromisoformat(raw["created_at"]),
        )
```

思考：为什么存储用 `to_dict()`？因为 JSON 不认识自定义 `Transaction` 对象。

## 6. 第三步：存储层

错误类型：

```python
class StorageError(Exception):
    """账本文件读写失败。"""
```

读取：

```python
import json
from pathlib import Path

def load_transactions(path: Path) -> list[Transaction]:
    if not path.exists():
        return []
    try:
        raw = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as exc:
        raise StorageError(f"无法读取账本：{path}") from exc

    try:
        return [Transaction.from_dict(item) for item in raw["transactions"]]
    except (KeyError, TypeError, ValueError) as exc:
        raise StorageError("账本结构不正确") from exc
```

保存使用临时文件替换：

```python
def save_transactions(path: Path, transactions: list[Transaction]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    data = {
        "version": 1,
        "transactions": [tx.to_dict() for tx in transactions],
    }
    temp = path.with_suffix(path.suffix + ".tmp")
    try:
        temp.write_text(
            json.dumps(data, ensure_ascii=False, indent=2),
            encoding="utf-8",
        )
        temp.replace(path)
    except OSError as exc:
        raise StorageError(f"无法保存账本：{path}") from exc
```

## 7. 第四步：业务层

```python
def add_transaction(
    path: Path,
    amount_cents: int,
    note: str,
    kind: str,
) -> Transaction:
    transactions = load_transactions(path)
    tx = Transaction.create(amount_cents, note, kind)
    transactions.append(tx)
    save_transactions(path, transactions)
    return tx

def summarize(transactions: list[Transaction]) -> tuple[int, int, int]:
    income = sum(tx.amount_cents for tx in transactions if tx.kind == "income")
    expense = sum(tx.amount_cents for tx in transactions if tx.kind == "expense")
    return income, expense, income - expense
```

service 不应 `print`，因为打印属于 CLI，测试 service 时也不需要收集输出。

## 3. 计划对象

```python
from dataclasses import dataclass
from pathlib import Path

@dataclass(frozen=True)
class MovePlan:
    source: Path
    destination: Path

@dataclass(frozen=True)
class MoveResult:
    source: Path
    destination: Path
    ok: bool
    error: str | None = None
```

## 4. 分类规则

按扩展名：

```python
def extension_folder(path: Path) -> str:
    suffix = path.suffix.lower().lstrip(".")
    return suffix if suffix else "no_extension"
```

`.JPG`、`.jpg` 应进入同一目录。

按日期：

```python
from datetime import datetime

def date_folder(path: Path) -> str:
    timestamp = path.stat().st_mtime
    return datetime.fromtimestamp(timestamp).strftime("%Y-%m")
```

更简单也可用 `%Y-%m-%d`。

## 5. 防重名

```python
def next_available(path: Path, reserved: set[Path]) -> Path:
    if not path.exists() and path not in reserved:
        return path

    counter = 1
    while True:
        candidate = path.with_name(f"{path.stem}_{counter}{path.suffix}")
        if not candidate.exists() and candidate not in reserved:
            return candidate
        counter += 1
```

`reserved` 防止两个源文件计划到同一个尚不存在的目标。

## 6. 生成计划

伪代码：

```text
build_plan(source, by):
    检查 source 存在且是目录
    plans = []
    reserved = set()

    for path in source.iterdir():
        如果 path 不是文件：跳过
        根据 by 计算结果目录名
        目标 = source / 目录名 / path.name
        目标 = next_available(目标, reserved)
        加入计划
        reserved.add(目标)

    return plans
```

只扫一层可避免把已经创建的 `jpg/` 再次扫描。若做递归，必须排除目标归档目录。

## 7. 执行计划

```python
import shutil

def move_file(source: Path, destination: Path) -> None:
    destination.parent.mkdir(parents=True, exist_ok=True)
    shutil.move(str(source), str(destination))
```

执行时逐个捕获异常：

```python
for plan in plans:
    try:
        move_file(plan.source, plan.destination)
        results.append(MoveResult(plan.source, plan.destination, True))
    except OSError as exc:
        results.append(
            MoveResult(plan.source, plan.destination, False, str(exc))
        )
```

最后打印成功、失败、跳过数量。

## 8. dry-run

```python
if args.dry_run:
    for item in plans:
        print(f"{item.source} -> {item.destination}")
    return 0
```

dry-run 只调用 `build_plan`，绝不能调用 `move_file`。

## 9. 测试重点

使用 `tmp_path`：

```python
def test_dry_run_does_not_move(tmp_path):
    source = tmp_path / "source"
    source.mkdir()
    file = source / "a.jpg"
    file.write_text("x", encoding="utf-8")

    plan = build_plan(source, "extension")

    assert plan[0].destination == source / "jpg" / "a.jpg"
    assert file.exists()
```

至少测：

1. `.jpg` 分到 `jpg/`。
2. 无后缀分到 `no_extension/`。
3. `.JPG` 和 `.jpg` 同组。
4. dry-run 不移动。
5. 真正移动到目标。
6. 重名文件自动 `_1`。
7. 空目录返回空计划。
8. 单个失败不阻塞其余文件。

## 10. 安全规则

- 只整理用户明确指定的目录。
- 正式执行前先 dry-run。
- 不扫描系统目录，不跟随不可信符号链接。
- 不在源目录和归档目录重叠时递归。
- 不覆盖已有文件。
- 失败要保留原文件并记录原因。

## 11. 完成标准

- extension 和 date 两种模式可用。
- dry-run 输出与真实移动目标一致。
- 重名不覆盖。
- 8 个测试通过。
- README 有高风险操作提示。

```python
    semaphore: asyncio.Semaphore,
```

## 5. 批量并发

```python
semaphore = asyncio.Semaphore(10)

async with httpx.AsyncClient(
    base_url="https://jsonplaceholder.typicode.com",
    timeout=httpx.Timeout(10.0),
) as client:
    tasks = [
        fetch_post(client, post_id, semaphore)
        for post_id in range(1, 21)
    ]
    results = await asyncio.gather(*tasks, return_exceptions=True)
```

`return_exceptions=True` 让异常作为结果返回，一遍汇总谁成功谁失败。
